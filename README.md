# 🏢 AssetVerse

**AssetVerse** is a corporate asset management system designed to efficiently manage company assets and employees with role-based access control.

---

## 🌐 Live URL
🔗 https://assetverse00.netlify.app/

---

## 🎯 Purpose
The purpose of AssetVerse is to help organizations track, assign, and manage corporate assets while maintaining secure access for employees and HR/admin roles.

---

## ✨ Key Features
- 👤 Employee & HR login system  
- 🔐 Role-based access control  
- ➕ Add, update, and delete assets  
- 📦 Assign assets to employees  
- 🔁 Manage returnable & non-returnable assets  
- 👥 Add and manage employees  
- 📊 Track asset allocation  
- 🎂 Upcoming birthdays & notifications  
- 📈 Overview dashboard for assets & employees  
- ⏳ Pending requests and approval system  
- 💳 Stripe integration for asset purchases  
- 📱 Fully responsive UI (desktop & mobile)  
- 🎨 Styled with Tailwind CSS & DaisyUI
