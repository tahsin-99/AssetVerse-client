# 🏢 AssetVerse

**AssetVerse** is a corporate asset management system designed to efficiently manage company assets and employees using secure, role-based access control.

---

## 🌐 Live URL
🔗 https://assetverse00.netlify.app/

---

## 🎯 Purpose

The goal of **AssetVerse** is to help organizations track, assign, and manage corporate assets while ensuring secure access for employees and HR/Admin roles.

## ✨ Key Features

- 👤 Employee & HR authentication  
- 🔐 Role-based access control  
- ➕ Add, update, and delete assets  
- 📦 Assign assets to employees  
- 🔁 Manage returnable & non-returnable assets  
- 👥 Add and manage employees  
- 📊 Track asset allocation history  
- 🎂 Upcoming birthdays & notification system  
- 📈 Dashboard overview of assets & employees  
- ⏳ Pending requests and approval workflow  
- 💳 Stripe integration for asset purchases  
- 📱 Fully responsive UI (desktop & mobile)  
- 🎨 Built with Tailwind CSS & DaisyUI

## 🚀 Setup Instructions

### 1️⃣ Clone the Repository
```bash
git clone https://github.com/your-username/assetverse.git
```

### 2️⃣ Navigate to the Project Directory
```bash
cd AssetVerse
```

### 3️⃣ Install Dependencies
```bash
npm install
```

### 4️⃣ Run the Development Server
```bash
npm run dev
```
